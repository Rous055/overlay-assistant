# Overlay Assistant

Персональный оверлей-ассистент для Windows: выпадает сверху экрана по хоткею
или по наведению курсора, содержит вкладки — почта, ссылки, скриншоты,
заметки, расписание, hh.ru, Moodle.

Это готовый **каркас** (окно, автозапуск, хоткей, наведение, трей,
минималистичный тёмный интерфейс с вкладками-заглушками). Модули с реальной
логикой (IMAP, hh.ru API, Moodle API и т.д.) добавляются по одному следующим шагом.

## Запуск в разработке

```bash
npm install
npm start
```

**start.bat** теперь запускает electron напрямую (`node_modules\electron\dist\electron.exe`),
минуя `npm`/консоль — это отдельный GUI-процесс, не привязанный к окну .bat.
Можно закрыть чёрное окошко .bat сразу после запуска, приложение продолжит работать.

При `npm start`/`start.bat` окно оверлея открывается через:
- хоткей `Ctrl+Shift+Space` (можно поменять в `main.js`, константа `HOTKEY`);
- наведение курсора в узкую зону по центру самого верха экрана.

При отведении курсора (и он не в зоне, и не над самим окном) панель
скрывается через ~350 мс.

Иконка в трее даёт быстрый доступ к показу/скрытию, включению автозапуска
и выходу.

## Автозапуск с Windows

`app.setLoginItemSettings({ openAtLogin: true })` реально работает только у
**собранного** (упакованного) приложения — у `electron .` в режиме разработки
это бессмысленно (привяжется к `electron.exe`). Поэтому в `main.js` эта
настройка включается только если `app.isPackaged === true`. Также автозапуск
можно включить/выключить вручную из меню трея.

## Сборка .exe для Windows

```bash
npm run build:win
```

Соберёт NSIS-инсталлятор через `electron-builder` (конфиг — в `package.json`,
секция `build`). После установки приложение само включит автозапуск.

## Модуль почты (Яндекс, только чтение) — готов

Реализовано через `imapflow` (чистый JS, без компиляции нативных модулей —
поэтому никаких проблем со сборкой типа тех, что были с `better-sqlite3`).

**Как подключить:**
1. Зайти в настройки Яндекс ID → раздел «Пароли приложений» →
   создать новый пароль приложения (тип — «Почта»).
2. В вкладке «почта» ввести адрес (`you@yandex.ru`) и этот пароль приложения
   (не обычный пароль от аккаунта — обычный IMAP не примет, если включена
   двухфакторная аутентификация, а для приложений это в любом случае надёжнее).
3. Нажать «Подключить» — при успехе сразу подгрузятся последние 20 писем.

Пароль хранится локально в зашифрованном виде (`safeStorage` из Electron,
использует встроенное шифрование Windows) в
`%APPDATA%\overlay-assistant\mail-config.json`. По сети никуда, кроме
Яндекс.IMAP (`imap.yandex.ru:993`), не уходит.

Кнопка «отключить» в списке писем удаляет сохранённые данные.

## Модуль ссылок — готов

Работает без базы данных — простой JSON-файл
(`%APPDATA%\overlay-assistant\links-store.json`), никаких нативных зависимостей.

**Как работает:**
- Приложение раз в секунду проверяет буфер обмена. Если там появляется новая
  ссылка (`http://...` / `https://...`) — она автоматически сохраняется в
  раздел «Входящие».
- Разделы (например «Учёба», «Работа») создаются вручную кнопкой «+» рядом со
  списком разделов.
- У каждой ссылки есть выпадающий список — можно перекинуть её в любой другой
  раздел. Крестик — удалить.
- Клик по самой ссылке копирует её обратно в буфер обмена (открывать браузер
  из оверлея пока не стали — сказать, если это нужно).

## Модуль скриншотов — готов

Приложение само находит стандартную папку скриншотов Windows (обычно
`Изображения\Screenshots` / `Pictures\Screenshots`, включая вариант в
OneDrive) и следит за ней — новый скриншот (Print Screen и т.п.) сразу
появляется в сетке во вкладке.

- Клик по миниатюре — выбрать/снять выбор (галочка в углу).
- Когда что-то выбрано, сверху появляются три действия:
  **открыть** (в программе просмотра по умолчанию), **копировать** (в буфер
  обмена — можно сразу вставить в чат/письмо), **в папке** (показать файл в
  проводнике).

## Модуль расписания — готов

Два режима, переключаются кнопками сверху вкладки:

- **личное** — как раньше: стрелки ← / → листают дни, «+ добавить дело»,
  галочка отмечает выполненным, крестик удаляет. Простой JSON-файл
  (`%APPDATA%\overlay-assistant\schedule-store.json`).
- **учёба** — фиксированное учебное расписание по дням недели (Пн–Сб),
  вшито прямо в приложение по присланному файлу деканата (4 курс, 4 группа
  ИВТ, I полугодие 26-27 уч.г.). Это статичные данные — при смене семестра
  нужно будет прислать новый файл, поправлю.

## Модуль Moodle — готов

Вход через логин/пароль от Moodle (обычно совпадают с университетскими) —
используется стандартный протокол мобильного приложения Moodle
(`login/token.php`, сервис `moodle_mobile_app`), отдельный API-ключ заводить
не нужно. Если у Moodle университета этот сервис отключён администратором —
будет соответствующая ошибка при входе, тогда нужно будет попросить
администратора включить веб-сервисы для мобильного приложения.

Четыре вкладки внутри:
- **дедлайны** — сроки сдачи заданий по всем курсам, отсортированы по дате;
- **оценки** — выставленные оценки по всем элементам курсов;
- **объявления** — последние записи из новостных форумов курсов;
- **материалы** — файлы/ссылки/страницы курсов, клик открывает материал.

Это MVP: дедлайны сейчас только из заданий (`mod_assign`), без тестов/квизов
и других типов активностей — расширим при необходимости. Сессия хранится
зашифрованно (`%APPDATA%\overlay-assistant\moodle-config.json`).

hh.ru убран — hh.ru отключил API для соискателей, доступа к откликам и
поиску вакансий через API больше нет. — слежение за буфером обмена (`clipboard-event` или поллинг
   `clipboard.readText()`), ручное распределение по разделам, хранение в SQLite.
3. **Скриншоты** — слежение за папкой скриншотов (`chokidar`), список последних,
   выбор + отправка.
4. **Заметки** — простое CRUD-хранилище в SQLite.
5. **Расписание** — ручной ввод дел по дням, хранение в SQLite.
6. **hh.ru** — OAuth-авторизация через HH API, отклики/статусы/подходящие вакансии.
7. **Moodle** — токен Moodle Web Services, дедлайны/оценки/объявления/материалы.

Хранение — везде локально (SQLite через `better-sqlite3`, уже в зависимостях),
синхронизация с внешними серверами не нужна.
